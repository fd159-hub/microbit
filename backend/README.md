# 校內限定教師進度服務

教師入口由 Google Apps Script 提供，部署執行身分為網站管理者，存取限制為「桃園市平鎮區復旦國民小學中的所有使用者」。Google 驗證校內帳號後，系統再驗證一組教師共用密碼；沒有額外的教師帳號註冊。

- 教師專區與教師上課模式都在同一個校內限定 Web App 中執行。
- 資料保存在該專案私有的 Script Properties。沒有姓名、Email 或學生名冊欄位。
- 密碼由 PBKDF2-SHA256（150000次）衍生，再雜湊保存驗證值；原始密碼不寫入程式碼或 GitHub。
- 登入憑證有效8小時；變更密碼會使其他登入憑證失效。
- 學年度至少115，班級限601～605；以學年度、班級與課程分別保存進度、備註、版本與更新時間。
- 寫入採版本檢查與Script Lock；遇到另一台電腦的新版本時顯示衝突，不直接覆寫。
- 學生的清除功能不會清除教師雲端進度。教師 MakeCode 作品僅存在目前瀏覽器，沒有跨電腦同步作品。

## 更新教師雲端頁面

教師頁面會將同一份課程 HTML／JavaScript／CSS 打包至 Apps Script。更新學生版並不會自動更新已部署的教師版；修改教學內容後，需重新打包並更新原 Web App 部署的版本。

1. 在儲存庫根目錄使用 `node backend/build-service.cjs`。透過標準輸入提供 JSON，格式為 `{"initialPassword":"自行設定至少8字元的初始密碼"}`。請使用安全的互動輸入，避免將密碼寫入指令歷程、檔案或版本控制。
2. 產物為已忽略的 `teacher-private/Code.gs`，只含鹽值與衍生驗證值，不含原始密碼。首次部署由管理者另行交付初始密碼；教師登入後可自行變更。
3. 將產物貼入既有的 Apps Script 專案並儲存。
4. 「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」，保持原部署ID、校內存取限制與執行身分。
5. 已存在的 Script Properties 會保留，因此更新版本不會重設目前教師密碼與教學進度。

目前 Apps Script 專案的連結由管理者保留；公開前端的 `teacher-config.js` 僅記錄經 Google 學校網域驗證的入口 URL。

## 驗證範圍

自動檢查涵蓋未登入拒絕、密碼驗證、有效期限、登出、密碼變更後舊憑證失效、學年度／班級隔離、非法步驟與寫入衝突。瀏覽器檢查另涵蓋教師登入、儲存、切換年度班級及重新開啟課程後接續。
