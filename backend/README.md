# 校內 Google 帳號教師進度服務

- 保持以管理者身分執行，入口僅限學校網域。
- 每次讀寫都透過 Session.getActiveUser().getEmail() 驗證實際登入者；只接受 @fdes.tyc.edu.tw，帳號為空或非此網域一律拒絕，不使用部署者帳號代替。
- 各教師以 Google 帳號雜湊、學年度、班級、課程分別保存，無共用密碼或額外帳號註冊。
- 資料保存在私有 Script Properties；前端不決定資料擁有者，也不能指定其他教師帳號。
- 舊共用進度保留在原屬性，不自動分配給任一教師。
- 學年度115起、班級601～605，保留步驟、備註、版本衝突檢查與 Script Lock。
- MakeCode 作品僅在本機瀏覽器，依教師、學年度、班級、課程分開。

## 更新部署

1. 執行 node backend/build-service.cjs，產生已忽略的 teacher-private/Code.gs。
2. 將程式貼入原 Apps Script 專案並儲存。
3. 管理部署作業 → 編輯 → 新版本 → 部署，保持原部署ID與校內存取限制。
4. 如 Google 要求新權限，由管理者確認帳號電子郵件讀取授權。
5. 以校內帳號驗證登入、儲存及重新載入；其他教師帳號應分開保存。
